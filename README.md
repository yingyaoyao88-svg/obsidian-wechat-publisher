# WeChat MP Publisher — Obsidian 公众号排版与发布工作台

在 Obsidian 里写好文章（配图、代码、公式、Mermaid 图、封面），在右侧工作台里：

1. **所见即所发**的公众号预览：27 款主题 × 4 种排版模板 + 高级微调，一键切换，可保存为「我的方案」；
2. 点「**推送到草稿箱**」：图片、公式、图表、封面自动上传微信，写入公众号草稿箱，逐步显示进度；
3. 或点「**复制排版**」：到公众号编辑器里 `Ctrl/Cmd+V`。

> **v0.2.0 起插件 ID 改为 `wechat-mp-publisher`**，以免和同名的另一个插件（RanceLee233/wechat-publisher，ID 为 `wechat-publisher`）互相覆盖。两个插件现在可以同时安装；从 0.1.0 升级的请看「更新插件」。

## 安装

> 仅支持**电脑版** Obsidian（Windows / macOS / Linux），版本 ≥ 1.4。手机版不可用。

### 方式一：下载安装包（推荐，不需要装任何开发工具）

1. 打开本仓库右侧的 **Releases**，下载最新版本里的 `wechat-mp-publisher-x.y.z.zip`。
2. 找到你的库（vault）所在文件夹，进入其中的 `.obsidian/plugins/` 目录；没有 `plugins` 文件夹就新建一个。
   - `.obsidian` 是隐藏文件夹。最简单的找法：Obsidian → 设置 → **第三方插件** → 「已安装插件」右边的 📁 **文件夹图标**，会直接打开 `plugins` 目录。
   - 或手动显示隐藏文件：macOS 在访达里按 `Cmd + Shift + .`；Windows 在资源管理器「查看 → 显示 → 隐藏的项目」。
3. 把 zip 解压到这里，得到的目录结构应该是：
   ```
   <你的库>/.obsidian/plugins/wechat-mp-publisher/
   ├── main.js
   ├── manifest.json
   └── styles.css
   ```
   ⚠️ 文件夹名必须是 `wechat-mp-publisher`，三个文件要直接在它下面，不能再多套一层文件夹。
4. 回到 Obsidian → 设置 → **第三方插件**：
   - 如果显示「安全模式 / 受限模式」，先点**关闭**（开启第三方插件）；
   - 点「已安装插件」右边的 🔄 **刷新**，列表里出现 **WeChat MP Publisher**，打开右侧开关。
5. 左侧功能区出现一个 ✈️ 纸飞机图标，就表示安装成功。

### 方式二：用 BRAT 插件安装（以后可自动更新）

1. 在 Obsidian 社区插件市场搜索安装 **BRAT**（Obsidian42 - BRAT）并启用；
2. 命令面板（`Ctrl/Cmd + P`）运行 **BRAT: Add a beta plugin for testing**；
3. 填入仓库地址 `https://github.com/yingyaoyao88-svg/obsidian-wechat-publisher`，确认；
4. 到「第三方插件」里启用 WeChat MP Publisher。

> 如果仓库是私有的，需要先在 BRAT 设置里填一个有该仓库读取权限的 GitHub Token。

### 方式三：从源码构建（开发者）

需要 Node.js 22+：

```bash
git clone https://github.com/yingyaoyao88-svg/obsidian-wechat-publisher.git
cd obsidian-wechat-publisher
npm install
npm run build        # 生成 main.js
```

然后把 `main.js`、`manifest.json`、`styles.css` 复制到 `<你的库>/.obsidian/plugins/wechat-mp-publisher/`，按方式一第 4 步启用。

### 更新插件

- 方式一：下载新版 zip，覆盖 `wechat-mp-publisher` 文件夹里的三个文件（`data.json` 是你的设置，**不要删**），然后在「第三方插件」里把开关关掉再打开。
- 方式二：BRAT 会自动检查更新，也可以运行命令 **BRAT: Check for updates to all beta plugins**。
- **从 0.1.0 升级**：0.1.0 装在 `plugins/wechat-publisher/`。先在「第三方插件」里关闭旧的 WeChat Publisher，把旧文件夹里的 `data.json` 复制到新的 `wechat-mp-publisher/` 文件夹（账号会自动迁移成新的多账号格式），再删除旧文件夹。

## 使用说明

### 工作台一览

点左侧 ✈️ 图标（或命令面板「打开公众号预览」），右侧打开一个干净的预览页：

```
[图标]                          [推送到草稿箱]  ⚙  ●
📄 正在预览 · 文章.md · 约 3,982 字
┌───────────────────────────────┐
│          封面（2.35:1）          │  ← 没有封面时显示「上传封面」，也可以直接把图片拖进来
│  文章标题                        │
│  作者                            │
│  正文（与推送内容是同一份 HTML）   │
└───────────────────────────────┘
```

| 元素 | 作用 |
|---|---|
| **推送到草稿箱** | 唯一的主按钮：上传正文图片、公式、图表和封面，写入草稿箱，完成后给出「去公众号发表」 |
| **封面** | 自动取正文第一张图；鼠标移上去点「更换封面」可从电脑 / 库中选择、用账号默认封面或恢复自动；也可以直接拖入图片。只影响本次发布，不改笔记 |
| **● 状态点** | 绿色 = 可以直接推送；琥珀色 = 有需要处理的问题（没封面、标题过长、正文超长等），点开查看；灰色 = 还没添加账号 |
| **⚙ 菜单** | 排版样式（主题、模板、主题色、字号、高级微调、我的方案）、复制排版、标题 / 作者 / 摘要、切换发布账号、管理账号、刷新、滚动同步、打开公众号后台、设置、帮助 |

> 笔记开头如果是 `# 标题`，它会被当作文章标题（公众号的标题是单独显示的），并从正文里去掉，避免标题出现两次。

### 第一次使用：添加公众号账号

> 只用「复制排版」可以跳过这一步；要「推送到草稿箱」必须添加账号。

1. 直接点「**推送到草稿箱**」，没有账号时会自动弹出添加账号窗口（也可以 ⚙ →「添加公众号账号」，或 设置 → WeChat MP Publisher → 管理账号）；
2. **最快的方式：快速粘贴新建**
   - 打开 [微信开发者平台](https://developers.weixin.qq.com/console) → 我的业务 → 你的公众号 →「**基础信息**」；
   - 在「开发密钥」处启用 AppSecret（扫码确认，只显示一次）；
   - 在该页面 `Ctrl/Cmd+A` 全选、复制，回到插件点「快速粘贴新建」，粘贴 → 插件自动识别账号名、AppID、AppSecret。
   - 也可以「手动新增」逐项填写。
3. **配置 IP 白名单**（首次必做）：在账号页的「IP 白名单」处点「**检测出口 IP**」→「**复制**」→「打开微信开发者平台」→ 基础信息 →「**API IP 白名单**」→ 设置名单，粘贴并确认，等 1～5 分钟生效；
4. 点「**测试连接**」看到 ✅ 即可。顺手填上默认作者、默认封面。

> 发布时如果遇到 **40164（IP 不在白名单）**，插件会直接弹出上面这个助手：显示微信看到的 IP、一键复制、打开平台、生效后点「重试」继续发布。
> 家庭宽带 IP 可能会变，开着代理/VPN 时微信看到的是代理 IP；再遇到时重复一次即可，旧 IP 不用删。
> AppSecret 明文保存在 `.obsidian/plugins/wechat-mp-publisher/data.json`，不要把它同步到公开仓库。

### 日常发文流程

1. **写文章**：图片直接拖进笔记（`![[图片.png]]` / `![](路径)`），代码用代码块，公式用 `$...$` / `$$...$$`，流程图用 ```` ```mermaid ````。
2. **看预览**：打开工作台，边写边看；需要换风格时在 ⚙ →「排版样式」里挑主题和排版模板。
3. **确认封面**：卡片顶部就是封面，不满意就点「更换封面」或拖入一张图；状态点是绿色就可以发了。
4. **发布**：点「推送到草稿箱」，看进度走完；插件会打开公众号后台，到「内容与互动 → 草稿箱」检查后发表。
5. **（可选）快捷键**：设置 → 快捷键，搜索「WeChat」，给「推送当前笔记到公众号草稿箱」绑定快捷键。

### 常见问题

| 现象 | 原因与解决 |
|---|---|
| 左侧没有 ✈️ 图标 / 插件列表里找不到 | 检查文件夹名是否为 `wechat-mp-publisher`、三个文件是否直接在其中；在「第三方插件」点刷新 |
| 40164 invalid ip | 本机出口 IP 不在白名单：按弹出的助手复制 IP 加入白名单后点「重试」 |
| 40125 / 40013 | AppSecret / AppID 不对，建议用「快速粘贴新建」避免复制错 |
| 48001 | 该公众号没有草稿箱接口权限，改用「复制排版」 |
| 提示「必须有封面」 | 点预览卡片顶部的「上传封面 / 更换封面」，或在笔记写 `cover:`，或给账号设置默认封面，或在正文放一张图 |
| 提示找不到图片 | 图片不在库里或路径写错；在 Obsidian 里能正常显示的图片都能找到 |
| 公式显示为 `$...$` 代码 | 公式语法有误（状态行会提示），在 Obsidian 里先确认能正常渲染 |
| 复制粘贴后部分图片不显示 | 未添加账号时图片以内嵌方式复制，个别图片需在编辑器里重新上传；添加账号后复制会先上传到微信 |
| 正文太长（45002） | 公众号要求正文少于 2 万字符，内联样式也算在内；状态行会按发布后的长度估算并提示，可拆分长文或换装饰较少的主题（如「极简」「Notion 风」） |
| 和另一个 WeChat Publisher 插件冲突 | v0.2.0 起 ID 已改为 `wechat-mp-publisher`，可以共存；两者都在左侧有图标，注意区分 |

## 支持的写法

| Obsidian 写法 | 公众号里的效果 |
|---|---|
| `![[图.png]]`、`![[图.png\|300]]`、`![说明](a.png)` | 上传到微信图床，居中，可指定宽度，alt 作为图注 |
| ```` ```ts ```` 代码块 | 语法高亮（One Dark / GitHub），Mac 三色圆点，横向滚动不折行 |
| `$E=mc^2$`、`$$...$$` 公式 | MathJax 渲染后转为高清 PNG 上传；行内公式与文字基线对齐，颜色跟随主题 |

| `[文字](https://...)` | 文字 + 上标 `[1]`，文末「参考链接」列出网址（公众号文章链接保持可点；公众号后台 `cgi-bin` 链接只保留文字，避免草稿接口报 invalid content） |

| `==高亮==`、`- [ ]` 任务、表格、嵌套列表、引用 | 对应样式 |
| `[[双链\|别名]]`、`%%注释%%`、frontmatter | 转为纯文本 / 删除 |
| 段落内直接回车换行 | 保留为换行（跟随 Obsidian「严格换行」设置）；首行缩进的模板里每一行都缩进 |

### 自定义主题

调色板主题：在 `src/render/palette-themes.ts` 里加一组配色即可。装饰主题：在 `src/render/theme.ts` 的 `DEFS` 里加一项：`build` 只写与基础样式不同的选择器；`decor` 声明需要真实插入的装饰：

| decor 字段 | 作用 | 对应可设置样式的选择器 |
|---|---|---|
| `headingPrefix` / `headingSuffix` | 标题前后加文字（emoji、`# ` 等） | `span.wx-h-pre` / `span.wx-h-suf` |
| `h2Number` | 二级标题自动编号 01、02… | `span.wx-h-num` |
| `quoteMark` | 引用块开头的大引号 | `section.wx-quote-mark` |
| `hr` | 用文字替代分隔线 | `section.wx-hr` |
| `ending` | 文末结束标记 | `section.wx-ending` |

公众号不支持 `::before/::after` 伪元素，所以这些装饰由渲染器插入真实元素。代码块外框（`section.wx-codeblock`）、图片、表格等也都可以按主题覆盖。

## 核心原理（为什么能“排版完全一致”）

**1. 公众号编辑器只保留内联样式。** 它会删掉 `<style>`、`class`、`id`，所以不能靠样式表。
插件用 markdown-it 把 Markdown 转成 HTML 后，把主题里每条「选择器 → 样式」逐个写进元素的 `style` 属性，
最后删除所有 class。代码高亮同理：highlight.js 生成的 `hljs-keyword` 等 class 被换成 `style="color:…"`。

**2. 代码块的空白必须显式化。** 公众号会折叠连续空格、忽略 `\n`，所以缩进空格 → `&nbsp;`，Tab → 4 个 `&nbsp;`，
换行 → `<br>`，再配合 `white-space:nowrap; overflow-x:auto` 让长行横向滚动。

**3. 图片必须在微信图床上。** 正文图片调用 `media/uploadimg`（仅 jpg/png、≤1MB）换成 `mmbiz.qpic.cn` 地址；
超限或 webp/bmp/svg 等格式先用 canvas 重新编码压缩；GIF 走 `material/add_material` 保留动图；
封面必须是永久素材的 `media_id`。已上传的图片按「路径+修改时间+大小」缓存，重复推送不会重复上传。

**4. 预览 = 发布。** 预览面板和发布调用同一个 `renderForWechat()`，只是图片地址不同（本地资源 vs 微信图床），
并且渲染在 Shadow DOM 里，隔离 Obsidian 自己的 CSS。

**5. 跨域。** 微信接口不允许浏览器跨域调用，插件使用 Obsidian 的 `requestUrl`（由 Electron 主进程发出）绕开 CORS。

## 开发

```bash
npm run dev    # 监听构建
npm test       # 渲染层单元测试（Node + jsdom，不依赖 Obsidian）
```

界面截图调试：`test/harness/` 里有一个 Obsidian API 替身，可以在普通浏览器里打开工作台和各个弹窗（见 `test/harness/entry.ts` 顶部的场景名）。

发布新版本：同步修改 `manifest.json`、`package.json` 的 `version` 并在 `versions.json` 加一行，提交到 `main` 后，到仓库的 **Actions → Release → Run workflow** 手动运行（或推送同名标签 `git tag 0.2.0 && git push origin 0.2.0`），会自动测试、构建、打标签并创建 Release。

## 已知限制

- 公式和 Mermaid 图以图片形式发布（公众号不支持脚本和 SVG 上传），发布后不能在编辑器里再改。
- 接口文档要求正文少于 2 万字符、小于 1MB；内联样式会占用字符数，超长文章建议拆分（预览面板会提示）。
- 仅桌面端可用（依赖剪贴板写入和 Electron 网络请求）。
